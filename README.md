# ShopNest 🛍️

A responsive e-commerce front end built with **React 19, Vite, Tailwind CSS 4, React Router and the Context API**.

## Features
- Home with hero, category cards and featured products
- Shop page with search, category, price and rating filters, plus sorting
- Product details: quantity selector, add to cart, buy now, reviews, related products
- Cart with quantity controls and live totals (persisted in localStorage)
- Wishlist with navbar counter
- Signup / login with protected routes (demo auth, localStorage)
- Checkout with address validation, order history and cancellation
- Profile editing and an admin dashboard (add/delete products, update order status)

## Run locally
```bash
npm install
npm run dev
```

Demo admin login: `admin@shopnest.com` / `admin123`

> Auth and data are stored in the browser for demo purposes. Swap the contexts for a real API when you add a backend.
